# Solar Estimator

A Persian RTL, responsive solar PV estimation PWA built with **Svelte 5, SvelteKit, TypeScript and SCSS** (no Tailwind).

Development work is proposed through feature branches and reviewed pull requests. Engineering results are preliminary estimates, not a substitute for detailed PV design or grid approvals.

See the `feat/sveltekit-solar-estimator-ui` branch for the initial application, English Codex specification, technical formulas and implementation audit.
